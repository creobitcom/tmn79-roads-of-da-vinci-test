# Test Assignment: Roads of Da Vinci

## О проекте
Проект игры в жанре Time Management на Unity.

## Требования
- **Unity:** `6000.0.72f1` (Unity 6)
- **Target Platform:** Standalone / Android

## Запуск проекта
1. Откройте Unity Hub и добавьте проект из папки `RoadsOfDaVinci`.
2. Дождитесь завершения первичного импорта ассетов и разрешения зависимостей Package Manager.
3. Основная сцена для запуска в редакторе:
   `RoadsOfDaVinci/Assets/_ProjectTemplate/Common/Bootstrap/Scenes/Bootstrap.unity`
